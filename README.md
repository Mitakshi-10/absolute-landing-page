# Absolut Raspberry Digital Experience

A premium, visually immersive landing page inspired by the iconic Absolut brand, crafted to showcase the vibrant character of Absolut Raspberry through modern storytelling, smooth interactions, and elegant product presentation.

## Overview

This project is a high-end brand experience website designed to capture the essence of Absolut Raspberry Vodka. The page combines editorial-style layouts, cocktail showcases, premium typography, and smooth scrolling interactions to create an engaging digital experience.

The design focuses on luxury, minimalism, and visual storytelling while highlighting signature raspberry-based cocktails and the brand's Swedish heritage.
